## G. Web y cookies
- [ ] Abrir la web en sesión limpia y registrar cookies/scripts antes de consentimiento.
- [ ] Comprobar que analítica/publicidad opcional no cargue antes de aceptar.
- [ ] Verificar que Aceptar/Rechazar tienen visibilidad equivalente.
- [ ] Revisar todos los formularios y su primera capa informativa.
- [ ] Revisar reCAPTCHA, Stripe, embeds y chat/KIA.
- [ ] Repetir auditoría al incorporar Meta Pixel, LinkedIn Insight, Google Ads u otros.

## H. KIA e IA
- [ ] Aprobar qué categorías de datos puede recibir cada proveedor IA.
- [ ] Aprobar categorías excluidas.
- [ ] Confirmar que no se usa contenido cliente para entrenamiento salvo configuración/base expresa.
- [ ] Revisar retención y configuración empresarial de los proveedores.
- [ ] Confirmar revisión humana para acciones sensibles.
- [ ] Revisar logs para evitar secretos/datos innecesarios.
- [ ] Revisar KIA tras cada nueva herramienta/capacidad.

- [ ] Definir cuánto tiempo se conserva.
- [ ] Decidir si se incorpora al expediente.
- [ ] Establecer regla especial para información sensible.
