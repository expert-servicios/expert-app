# Checklist humano RGPD — EXPERT ESTUDIOS PROFESIONALES, SLU

Fecha: 24/09/2026

Este checklist contiene únicamente tareas que requieren decisión, validación, firma o ejecución humana. KIA puede preparar borradores y evidencias, pero no debe marcar estas tareas como cerradas por sí sola.

## A. Dirección y criterio jurídico
- [ ] Confirmar el inventario real de tratamientos.
- [ ] Aprobar la finalidad y base jurídica de cada tratamiento.
- [ ] Aprobar el rol de EXPERT como responsable/encargado por cada familia de servicios.
- [ ] Aprobar el RAT final.
- [ ] Aprobar la matriz de conservación.
- [ ] Documentar decisión sobre DPD: obligatorio / no obligatorio / voluntario.
- [ ] Aprobar el análisis de riesgos.
- [ ] Decidir y documentar si alguna capacidad requiere EIPD.
- [ ] Aprobar el uso de IA/KIA y sus límites.
- [ ] Aprobar la política de notas automáticas de Google Meet.

## B. Proveedores y contratos
- [ ] Revisar DPA de Supabase.
- [ ] Revisar DPA/condiciones de Vercel.
- [ ] Revisar rol y documentación de Stripe.
- [ ] Revisar DPA de Resend.
- [ ] Revisar Google Workspace y Google Cloud.
- [ ] Revisar Microsoft 365 si continúa como canal operativo.
- [ ] Revisar Holded.
- [ ] Revisar Anthropic.
- [ ] Revisar OpenAI.
- [ ] Revisar Meta/WhatsApp cuando se active.
- [ ] Revisar Telegram para contenido permitido.
- [ ] Revisar reCAPTCHA.
- [ ] Archivar evidencia/versiones de DPAs y subencargados.

## C. Hallazgos P1 de documentación pública
- [ ] Corregir Supabase: eu-west-2 / Londres; la web dice actualmente Frankfurt.
- [ ] Revisar y corregir la lista pública de proveedores para que coincida con integraciones reales.
- [ ] Corregir el texto de conservación de datos que usa una referencia genérica de 5 años.
- [ ] Revisar cómo se describe el rol de Stripe.
- [ ] Añadir Calendar/Meet/notas automáticas.
- [ ] Revisar transferencias internacionales proveedor por proveedor.
- [ ] Actualizar fecha de la Política de Privacidad tras la revisión.

## D. Accesos y seguridad
- [ ] Revisar usuarios con acceso a Supabase, Google, Microsoft, Holded, Stripe, Vercel, GitHub y demás sistemas.
- [ ] Revocar accesos antiguos.
- [ ] Confirmar MFA en cuentas con acceso a datos.
- [ ] Confirmar uso de cuentas individuales, no compartidas.
- [ ] Revisar permisos mínimos por rol.
- [ ] Revisar copias de seguridad.
- [ ] Ejecutar prueba de restauración.
- [ ] Revisar dispositivos con acceso a datos.
- [ ] Confirmar procedimiento de alta/baja de personal/colaboradores.

## E. Personal y colaboradores
- [ ] Firmar/actualizar compromiso de confidencialidad.
- [ ] Entregar instrucciones de seguridad y privacidad.
- [ ] Realizar formación inicial.
- [ ] Programar recordatorio/formación anual.
- [ ] Confirmar devolución de activos y revocación al finalizar colaboración.

## F. Derechos y brechas
- [ ] Designar responsable humano para solicitudes de derechos.
- [ ] Probar el correo/canal de entrada.
- [ ] Ejecutar un simulacro de acceso/supresión.
- [ ] Designar responsable humano de brechas.
- [ ] Ejecutar simulacro de brecha.
- [ ] Aprobar criterio de escalado y comunicación.

## G. Web y cookies
- [ ] Abrir la web en sesión limpia y registrar cookies/scripts antes de consentimiento.
- [ ] Comprobar que analítica/publicidad opcional no cargue antes de aceptar.
- [ ] Verificar que Aceptar/Rechazar tienen visibilidad equivalente.
- [ ] Revisar todos los formularios y su primera capa informativa.
- [ ] Revisar reCAPTCHA, Stripe, embeds y chat/KIA.
- [ ] Repetir auditoría al incorporar Meta Pixel, LinkedIn Insight, Google Ads u otros.

## H. KIA e IA
- [ ] Aprobar qué categorías de datos puede recibir cada proveedor IA.
- [ ] Aprobar categorías excluidas.
- [ ] Confirmar que no se usa contenido cliente para entrenamiento salvo configuración/base expresa.
- [ ] Revisar retención y configuración empresarial de los proveedores.
- [ ] Confirmar revisión humana para acciones sensibles.
- [ ] Revisar logs para evitar secretos/datos innecesarios.
- [ ] Revisar KIA tras cada nueva herramienta/capacidad.

## I. Reuniones y notas
- [ ] Decidir si las notas automáticas se activan para todas las reuniones o solo determinadas categorías.
- [ ] Aprobar el aviso previo al participante.
- [ ] Definir quién accede al resumen.
- [ ] Definir cuánto tiempo se conserva.
- [ ] Decidir si se incorpora al expediente.
- [ ] Establecer regla especial para información sensible.

## J. Cierre
- [ ] Firmar/fechar RAT.
- [ ] Firmar/fechar análisis de riesgos.
- [ ] Firmar/fechar decisión DPD.
- [ ] Firmar/fechar decisión EIPD.
- [ ] Confirmar carpeta de evidencias.
- [ ] Establecer revisión anual.
- [ ] Establecer revisión extraordinaria ante nuevas integraciones, IA, servicios o categorías de datos.
